# SalesSystem はじめてガイド

目安: **5〜10分**

## SalesSystemは何のためのもの？

SalesSystem（画面名: 営業管理システム）は、社員が日々の営業・顧客対応を一か所で進める社内システムです。

正式に付き合う会社・団体は「組織」、まだ電話してみる段階の大量候補は「営業リスト / 営業候補」、Webフォームからの相談は「お問い合わせ」で扱います。対応したことは「対応履歴」、これからやることは「次回アクション」に残します。

顧客管理だけではありません。メディア・自治体・学校・パートナーなども組織として管理でき、インサイドセールスの架電も同じシステムで進められます。

## まずこれだけ覚える

1. ログインしたら **マイデスク**
2. 正式に付き合う会社・団体は **組織**
3. 大量の営業先候補は **営業リスト**（いきなり組織へ入れない）
4. Webフォームから来たものは **お問い合わせ**
5. 営業候補への電話は **今日の営業 / 架電キュー**
6. 電話したら必ず **結果を保存**（保存して次へ）
7. 次に電話する日時があれば **次回連絡**
8. 正式組織でやったことは **対応履歴**
9. 次にやることは **次回アクション**
10. 迷ったら **検索してから** 新規作成

## どこに登録する？（最重要早見表）

| 状況 | 登録先 |
|---|---|
| 契約中の会社 | 組織 / 顧客 |
| 具体的な商談中 | 組織 / 見込顧客 |
| 出版社・テレビ・Webメディア | 組織 / メディア |
| 自治体 | 組織 / 自治体 |
| 大学・研究室 | 組織 / 学校・研究機関 |
| 協業パートナー | 組織 / パートナー |
| 顧客かつパートナー | 同じ組織に関係性を複数 |
| 営業用5000社CSV | 営業リスト |
| 展示会で集めた候補 | 営業リスト |
| スクレイピング候補 | 営業リスト |
| Webフォームからの相談 | お問い合わせ |
| 正式組織への電話 | 対応履歴 |
| 営業候補への電話 | 架電結果 |
| これからやること（正式組織） | 次回アクション |
| 営業候補の再架電予定 | 次回連絡 |
| 具体商談 | 案件 |
| 契約情報 | 契約（請求書は freee） |
| 重大トラブル | クレーム |
| 会社名しか覚えていない | 全体検索 |
| 今日やることの確認 | マイデスク |

## 3つの基本フロー

### A. 問い合わせ

```
お問い合わせ
  → 担当を決める
  → 既存組織を確認
  → 紐付け / 新規作成
  → 返信（Gmail下書き → 人が送信）
  → 対応履歴
  → 次回アクション
```

### B. 新規営業

```
営業リスト
  → 担当割当
  → 架電
  → 結果保存
  → 再架電
  → 興味あり / アポ
  → 正式組織へ昇格
```

### C. 既存顧客対応

```
検索
  → 組織
  → 対応
  → 対応履歴
  → 次回アクション
  → 必要なら案件
```

## 混同しやすい3つ（超短縮）

- **見込顧客** = 正式な組織の関係性 / **営業候補** = リスト上の候補
- **対応履歴** = 過去 / **次回アクション** = 未来
- **興味なし** = 今回の対象外 / **営業連絡不要** = 今後の営業架電対象外
