# SalesSystem 用語集

社員向け。内部コード名（Prospect 等）は必要なときだけ括弧で補足します。

## 担当者は3種類ある（必読）

```
株式会社さくらケア
  先方担当者 …… 山田様（相手会社の人）
  自社担当者 …… 石川（うちの社員）
  石川の権限 …… 担当者（ログイン役割名）
```

同じ「担当者」でも意味が違います。組織メニューの「担当者」は基本的に **先方担当者** です。

---

## 組織

正式に会社と関係を持つ会社・団体。  
顧客・見込顧客・メディア・自治体・学校・研究機関・パートナーなどを含みます。  
大量の未精査リストはここに直接入れません。

## 顧客

組織の関係性のひとつ（購入・契約済みなど）。  
ナビの「顧客」は組織一覧のフィルタです。

## 見込顧客

正式な「組織」の一種。すでに具体的な関係を持ち始めた会社に付ける関係性です。

## 営業候補

まだ営業リスト上で電話してみる段階の候補です。  
見込顧客（組織）とは別物です。

### 一本道の例

```
介護施設CSV 3000社
  → 営業候補
  → 電話
  → アポ獲得
  → 正式組織へ昇格
  → 見込顧客
```

## 営業リスト

大量の営業候補をまとめて管理する単位。  
担当割当・架電進捗・KPIをリスト単位で見られます。

## 先方担当者

相手会社側の人物。例: 山田様（施設長）。

## 自社担当者

うちの社員。案件や次回アクションの担当として設定します。

## 権限の「担当者」

ログイン権限の役割名（管理者 / 運用責任者 / **担当者** / 閲覧者）。  
先方・自社の担当者とは別概念です。

## 案件

具体的な営業商談。興味ありだけでは作らず、条件が具体化したタイミングがおすすめです。

## 対応履歴

**過去**に何をしたかの記録（電話・訪問・メールなど）。

## 次回アクション

**未来**にやること（ToDo）。期限と完了があります。

### 注意

対応履歴フォーム内の「当時入力した次回予定（履歴メモ）」は対応時点の記録です。
実際のToDoは「次回アクション」として登録します。

## 次回連絡

営業候補への再架電予定日時。正式組織側の次回アクションとは別です。

## お問い合わせ

Webフォームなどから来た相談の受信箱。通常のGmail全部を取り込むものではありません。

## 興味なし

今回の営業対象として対象外にする架電結果。DNCにはしません。

## 営業連絡不要（DNC）

今後の営業架電対象から外す設定。影響が大きいです。  
同じ会社が別リストにあっても再架電対象になりません。

## 正式組織化（昇格）

営業候補を正式な組織として登録すること。**手動**です。自動では顧客になりません。

## 架電キュー / 今日の営業

自分の担当営業先へ順番に電話する画面。自動発信はしません。

## マイデスク

ログイン後にまず見るホーム画面。

## 請求関連について

請求書の作成・発行・管理は **freee** で行います。  
SalesSystemでは契約情報までを管理します。
